# صفحهٔ خانهٔ «ماه»

خانه عمداً خلوت است تا با یک نگاه بفهمی کجایی و فردا ممکن است چه حسی داشته باشی.

## الان روی خانه می‌بینی
- حلقهٔ چرخه + عنوان مرحلهٔ امروز
- یک کارت کوتاه برای زمان پریود بعدی (یا تأخیر)
- کارت **فردا ممکنه چی حس کنی** (خلق + هوس؛ با ضربه جزئیات علمی)
- خلاصهٔ کوتاه **در بدنم چه می‌گذرد؟**
- دکمهٔ **پریودم شروع شد** (یا ثبت پایان)
- لینک کم‌رنگ «ثبت حال و امکانات بیشتر» → تب ثبت

## پیش‌بینی فردا
از روی مرحلهٔ تخمینی **فردا** (نه فقط امروز) ساخته می‌شود. متن‌ها آموزشی‌اند («ممکنه»)، با توضیح سادهٔ هورمون‌ها (استروژن، پروژسترون، پروستاگلاندین، سروتونین، آهن/منیزیم) و بدون تشخیص پزشکی.
