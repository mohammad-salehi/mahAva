# ماه‌آوا — امکانات ویژه و هوس خوراکی

## هوس خوراکی (رایگان)
- در «ثبت حال امروز» می‌توانی هوس‌ها را علامت بزنی: شکلات، شیرینی، شور، نان/کربوهیدرات، تند، لبنیات، گوشت قرمز، کافئین، چیز دیگر.
- روی کارت امروز و صفحهٔ «هوس خوراکی» معنی آموزشی رایج در همان مرحلهٔ چرخه نشان داده می‌شود (با زبان «ممکنه / گاهی»).
- این‌ها تشخیص پزشکی نیستند.

## اشتراک آزمایشی (محلی)
پرداخت واقعی هنوز وصل نیست. از **تنظیمات → اشتراک → فعال‌سازی آزمایشی اشتراک** روشن کن.

بعداً می‌تواند به بکند `darapfm.ir/mah` وصل شود؛ فعلاً فقط پرچم محلی DataStore است.

## امکانات ویژه
1. **بینش روزانه** — متن شخصی از مرحله + حال/درد/خواب/هوس
2. **الگوی علائم** — خوشه‌بندی علائم در مراحل چرخه (حداقل ۲ چرخه)
3. **روند چرخه** — نمودار طول چرخه، مدت خون‌ریزی، علائم پرتکرار
4. **بررسی آموزشی علائم** — پرسشنامهٔ هم‌پوشانی PCOS / اندومتریوز با هشدار قوی «تشخیص نیست»
